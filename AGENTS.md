# AGENTS.md

This repository's canonical agent instructions live in `CLAUDE.md`.

AI coding agents and automated coding harnesses should read `CLAUDE.md` before making changes in this repo and follow it as the shared development directive. Where `CLAUDE.md` names Claude Code or uses Claude-specific framing, interpret that as applying to the current agent/harness unless the instruction is explicitly tool-specific.

Do not maintain a second copy of those rules here. Keeping this file as a pointer avoids drift between agent harnesses.
